# 6th Dry Clean | دراي كلين السادس

Separate bilingual website for 6th Dry Clean in Amman, Jordan.

Arabic-first RTL layout, English switch, service information, telephone and Facebook links, and WhatsApp enquiry form. Real stock photography and subtle animations with reduced-motion support.

Static files are in the repository root. No build required.
